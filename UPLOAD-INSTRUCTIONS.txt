BLISKO 1.9.1 - INTERACTIVE PROGRESS DETAILS

Upload the full contents of this folder to the same web location as the previous build.

Version 1.9.1 makes all four summary cards on the Progress screen interactive. The corner icons open detailed level, vocabulary, streak-calendar, and conversation-readiness views while preserving the compact overview.

After deployment, open the app once while online so the service worker can install the 1.9.1 shell. If an older screen remains visible, use Settings > Repair downloaded app files once. Learning progress is not deleted.
